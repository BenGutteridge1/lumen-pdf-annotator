# Security policy

## Supported versions

Security fixes are provided for the latest released version of Lumen PDF Annotator.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of opening a public issue. Include a concise impact description, reproduction steps, affected version, and a minimal synthetic file when a document is required.

Do not submit private PDFs, vault contents, credentials, or personal information. You should receive an acknowledgement within seven days. A public disclosure timeline will be coordinated after a fix is available.

## Data boundary

Lumen processes PDFs locally and does not include telemetry, accounts, remote processing, or dynamically loaded code. Annotations and recovery data remain in the user's Obsidian vault.
