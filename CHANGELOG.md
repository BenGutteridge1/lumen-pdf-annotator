# Changelog

## 0.6.1

- Added a floating, searchable and virtualized annotation inspector.
- Added per-highlight editing for notes, tags, colour, and mark style.
- Added light, sepia, and dark PDF themes.
- Added full-document PDF search with global `Cmd/Ctrl+F` routing.
- Added reader hotkeys and compact floating controls.
- Added content-addressed PDF backups and Markdown annotation snapshots.
- Added large-annotation-set indexing, journaling, and performance tests.
- Made search and annotation panels start closed on every PDF load.
- Centred annotation empty states within the complete inspector result frame.
